# Inspect a user-process page table

```
va 0x0 pte 0x21FC885B pa 0x87F22000 perm 0x5B
va 0x1000 pte 0x21FC7C17 pa 0x87F1F000 perm 0x17
va 0x2000 pte 0x21FC7807 pa 0x87F1E000 perm 0x7
va 0x3000 pte 0x21FC74D7 pa 0x87F1D000 perm 0xD7
va 0x4000 pte 0x0 pa 0x0 perm 0x0
va 0x5000 pte 0x0 pa 0x0 perm 0x0
va 0x6000 pte 0x0 pa 0x0 perm 0x0
va 0x7000 pte 0x0 pa 0x0 perm 0x0
va 0x8000 pte 0x0 pa 0x0 perm 0x0
va 0x9000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFF6000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFF7000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFF8000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFF9000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFFA000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFFB000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFFC000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFFD000 pte 0x0 pa 0x0 perm 0x0
va 0xFFFFE000 pte 0x21FD08C7 pa 0x87F42000 perm 0xC7
va 0xFFFFF000 pte 0x2000184B pa 0x80006000 perm 0x4B
```

Virtual address, page table entries, physical address, permission bits

1) `va 0x0 pte 0x21FC885B pa 0x87F22000 perm 0x5B`
- Permission bits: 0b01011011.
    - Accessed
    - User
    - Executable
    - Readable
    - Valid

This is the machine instructions (text). It is user accessed and executable.

2) `va 0x1000 pte 0x21FC7C17 pa 0x87F1F000 perm 0x17`
- Permission bits: 0b00010111
    - User
    - Writable
    - Readable
    - Valid

This seems like an unused page that is just left as a spacer.

3) `va 0x2000 pte 0x21FC7807 pa 0x87F1E000 perm 0x7`
- Permission bits: 0b00000111
    - Writable
    - Readable
    - NOT User
    - Valid

This looks like the data (global and static variables) because it is readable, but not executable and accessed by the user.

4) `va 0x3000 pte 0x21FC74D7 pa 0x87F1D000 perm 0xD7`
- Permission bits: 0b11010111
    - Dirty
    - Accessed
    - User
    - Writable
    - Readable
    - Valid

This seems like it is the guard page (it is dirty) before the stack and other data.

5) `va 0x4000 pte 0x0 pa 0x0 perm 0x0` - `va 0x9000 pte 0x0 pa 0x0 perm 0x0` and `va 0xFFFF6000 pte 0x0 pa 0x0 perm 0x0` - `va 0xFFFFD000 pte 0x0 pa 0x0 perm 0x0`
- Permission bits: 0b00000000

These seem like the beginning of stack and heap and also the unused extra memory.

6) `va 0xFFFFE000 pte 0x21FD08C7 pa 0x87F42000 perm 0xC7`
- Permission bits: 0b11000111
    - Dirty
    - Accessed
    - NOT User
    - Writable
    - Readable
    - Valid

This seems to be the trapframe because it is next to the trampoline and can be written and executed, but not accessed by the user.

7) `va 0xFFFFF000 pte 0x2000184B pa 0x80006000 perm 0x4B`
- Permission bits: 0b01001011
    - Accessed
    - NOT User
    - Executable
    - Readable
    - Valid

This seems to be the trampoline as it is at the highest virtual memory value, is not accessed by the user, and is executable and readable.
